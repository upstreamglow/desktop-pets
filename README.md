# 桌宠 · Desktop Pets

一组 Windows 桌面小宠物。每个都是**单文件 exe**，双击就能用，不用安装。

> **下载请到右侧的 [Releases](../../releases) 页面**，本仓库主分支只有说明文档，不含程序与源码。

---

## 这是什么

桌面上会多出一个 Q 版小人，她有这些性格：

| 互动 | 效果 |
|---|---|
| **打字** | 你按键盘，她跟着敲键盘，键帽会亮起来 |
| **点她** | 说一句角色的经典台词（小气泡） |
| **不管她** | 过一会儿开始打瞌睡、点头、冒 Zzz |
| **静静待着** | 有呼吸起伏，不会死板 |

- 鼠标**穿透**：点得到她下面的图标，不挡事
- **可拖动**：按住她拖到你喜欢的位置
- 不要音效，安静陪伴型

---

## 怎么用

1. 去 [Releases](../../releases) 页面，下载你想要的 `.exe`
2. 放到桌面（或者任何文件夹）
3. **双击运行**

> ⚠️ 第一次运行 Windows 可能提示「已保护你的电脑 / Windows Defender SmartScreen」。
> 这是所有未签名程序的正常提示，点 **「更多信息」→「仍要运行」** 即可。
>
> 想让它开机自动启动：按 `Win + R`，输入 `shell:startup`，把 exe 的**快捷方式**丢进去。

## 常见问题

**Q：双击没反应？**
A：程序会安静地待在桌面右下角区域，可能需要几秒加载（单文件 exe 首次运行要解压）。看看任务栏有没有。

**Q：杀毒软件报毒？**
A：PyInstaller 打包的程序常被误报。加白名单即可。本仓库程序不含任何联网行为。

**Q：怎么关掉？**
A：右键任务栏图标 → 关闭窗口；或任务管理器结束对应进程。

**Q：想放多个一起用？**
A：可以，重复放不同角色即可。
